# Virtual Light Development Project

このリポジトリは、そのままUnity Hubから開けるVirtual Light開発プロジェクトです。

- UPM package: `Packages/com.mizot.virtual-light`
- シンプルなPackage sample: Package Managerの`Basic Virtual Lights`
- 高度な実例: `Assets/VirtualLightExamples/Advanced`

最初はPackage ManagerからBasic sampleをImportし、Point、Spot、Rectangle Areaの静的な比較を確認してください。Areaの片面／両面方向性、遮蔽、PBR比較、複数beam、moving head演出、性能調整はAdvanced examplesで確認できます。

Git URLからpackageだけを導入する場合は、URLに`?path=/Packages/com.mizot.virtual-light`を付けます。
